## 完了の考え方

実装したこと、機械的に確認したこと、人が試して確認したことを分けて記録します。
課題には目的、範囲、成果物、受入条件を書き、変更はPRで確認します。
「動いたという報告」だけで、実機や利用者の確認まで終わったとは扱いません。

内部コード、認証情報、実行ログ、個人の保存場所は、このリポジトリの対象に含めません。
作品のすべてのソースコードを公開するリポジトリではありません。

## 反応を寄せる

試遊した環境、実際にできたこと、止まった箇所、次に試したくなったことをIssuesへお寄せください。
未公開の情報や個人情報は書き込まないでください。
