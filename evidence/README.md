# 成果物と確認状態

| 成果物 | 現在の扱い | 確認の境界 |
|---|---|---|
| ActionTri紹介資料 | 開発中の説明資料 | 身体入力・人の試遊・別PCの受入とは別 |
| ActionTri紹介映像 | 公開候補を準備 | 実画面の静止画による紹介と操作の実演を区別 |
| 費用計算サンプル | オフラインの再現例 | 仮想データの計算。実測費用や現行価格ではない |

検証結果には、実施条件、実施件数、失敗、スキップ、未確認事項を残します。
公開する成果物には版とSHA-256を付け、説明と実物の取り違えを防ぎます。
大きな配布物は、確認を終えた版をReleasesなどの配布先から案内します。
